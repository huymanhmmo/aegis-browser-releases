## 🌟 Tính Năng Nổi Bật

- **Kiến trúc Lõi kép (Dual Engine)**: Hỗ trợ linh hoạt cả **Chromium** hiện đại và **Camoufox (Gecko)** siêu bảo mật.
- **Cô lập vân tay phần cứng (Fingerprint Spoofing)**: Canvas, WebGL, AudioContext, Client Rects, Font fingerprint, và Navigator parameters được tạo ngẫu nhiên nhưng đồng nhất cho từng Profile.
- **WebRTC Shield & Proxy Loopback Tunnel**: Chống rò rỉ IP thật 100%, hỗ trợ HTTP, SOCKS5, SSH Proxy riêng biệt theo từng hồ sơ.
- **Bảo mật 2FA Authenticator tích hợp**: Quản lý mã OTP 6 số trực tiếp trong từng profile, không cần mở điện thoại.
- **Tiện ích mở rộng đóng gói sẵn**: Tích hợp sẵn VPN thương mại và Studio kịch bản tự động hóa RPA.

## 🚀 Hướng Dẫn Sử Dụng

### 1. Dành cho Bản Cài Đặt (.EXE)
1. Tải file `AegisBrowser_Setup_v0.1.0.exe`.
2. Nhấp đúp để cài đặt tự động. Trình cài đặt sẽ tạo Shortcut tiện lợi ngoài màn hình Desktop.
3. Mở ứng dụng và bắt đầu tạo Profile duyệt web an toàn.

### 2. Dành cho Bản Portable (.ZIP)
1. Tải file `AegisBrowser_v0.1.0_Windows_x64.zip`.
2. Giải nén vào thư mục bất kỳ trên ổ cứng (ví dụ `D:\AegisBrowser`).
3. Chạy trực tiếp file `AegisBrowser.exe` (không cần cài thêm bất kỳ phần mềm phụ trợ nào).
